. Start the pzgis frontend

From your Fish shell:

cd ~/pzgis
source .venv/bin/activate.fish
python3 frontend.py

You should see Uvicorn start and listen on port 8000.

Leave this terminal running.
2. Open the frontend

In your browser, go to:

http://localhost:8000

That is the pzgis frontend provided by frontend.py.
